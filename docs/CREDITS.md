## 差し替え推奨：建石さん自身の写真を使う

このページの写真は「暫定」。CC素材にはbase44級の編集写真が存在せず、質で必ず見劣りする。α7C II があり、実際の現場（三田・気仙沼・Kawara454・さんだ住まいるフェスタ）にアクセスできる以上、**自前写真がそのまま最大の差別化**になる。ライセンス問題も消える。

### 撮影リスト（このページに必要な4枚）

| 用途 | 比率 | 内容 | 撮り方 |
| :---- | :---- | :---- | :---- |
| **コラージュ中央** | 縦4:3.7 (900×840) | 改装した空間で人が作業／集まっている場面。手・道具・素材が散らかっているほど良い | やや俯瞰。人物2〜4名。**整えすぎない**。自然光、日中の窓際 |
| **エディトリアル背景** | 横16:9 (1440×810) | 同じ空間の引き。人の営みが分かる全景 | 水平を出す。左1/3に余白（文字が乗る）。デュオトーン前提なので明暗のコントラストを重視 |
| **手元の寄り**（追加候補） | 正方形 | 図面・メジャー・スマホで採寸している手元 | 寄りで浅い被写界深度。ブランドの朱に近い色を1点入れる |
| **ビフォー**（追加候補） | 横16:9 | 手つかずの空き家。ただし**廃墟感を出さない** — 光の入る昼、埃より木の質感 | 三脚・低ISO。暗く撮らない |

### 加工レシピ（`img-*.webp` と同じ処理）

warm=1.05  \# R×1.05 / B×0.95

sat=0.95  con=1.10  bright=1.04

\# デュオトーン: グレースケール → autocontrast(cutoff=2) → contrast×1.35

\#   → colorize(black=(18,17,22), mid=(122,52,40), white=(255,140,84))

書き出しは WebP quality 78〜82。ページ側で粒子（SVGノイズ）を `mix-blend-mode:multiply` opacity .22 で重ねる。

## 差し替え手順（base64からの外部化は実装済み）

画像はすでに `apps/web/public/img/` に外部ファイルとして配置されています。

| ファイル | 使用箇所 |
| :---- | :---- |
| `img-studio.webp` | コラージュ中央（`.collage .ph`） |
| `img-halftone.webp` | 網点バンド（`.htband`） |
| `img-studio_duo.webp` | エディトリアル背景（`.editorial .bgph`） |
| `tex-canvas.png` | 布地テクスチャ（`--tex-canvas`。写真ではないので差し替え不要） |

差し替えるときは:

1. 上表の比率で書き出し、**同じファイル名**で `apps/web/public/img/` に上書き
2. `apps/web/src/app/page.tsx` 内の `alt` を実際の内容に合わせて書き換える
3. ページ下部のクレジット行を削除
   （`apps/web/src/app/page.tsx` の `<p className="phcap">Photo: Double Union ...</p>`）
4. この `CREDITS.md` の該当行を削除
