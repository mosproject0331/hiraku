## 自前写真に差し替えたくなったら

イラストは「写真がなくても成立する」ための解であって、
**実際の現場写真のほうが強いのは変わりません**。α7C II と現場（三田・気仙沼・Kawara454・
さんだ住まいるフェスタ）にアクセスできるなら、撮った写真に差し替える価値は十分あります。

### 撮影リスト

| 用途 | 比率 | 内容 | 撮り方 |
| :---- | :---- | :---- | :---- |
| **コラージュ中央** | 縦4:3.7 (900×840) | 改装した空間で人が作業／集まっている場面。手・道具・素材が散らかっているほど良い | やや俯瞰。人物2〜4名。**整えすぎない**。自然光、日中の窓際 |
| **エディトリアル背景** | 横16:9 (1440×810) | 同じ空間の引き。人の営みが分かる全景 | 水平を出す。左1/3に余白（文字が乗る）。デュオトーン前提なので明暗のコントラストを重視 |
| **網点バンド** | 横5:2 (1400×560) | 作業風景。網点化するので細部より明暗の塊が大事 | 逆光ぎみでも可。潰れやすいので明るめに |
| **手元の寄り**（追加候補） | 正方形 | 図面・メジャー・スマホで採寸している手元 | 寄りで浅い被写界深度。ブランドの朱に近い色を1点入れる |

### 加工レシピ

```
warm: R×1.05 / B×0.95
sat 0.95 / con 1.10 / bright 1.04

デュオトーン（エディトリアル用）:
  グレースケール → autocontrast(cutoff=2) → contrast×1.35
  → colorize(black=(18,17,22), mid=(122,52,40), white=(255,140,84))

網点（バンド用）:
  autocontrast(cutoff=2) → 明度1.12 → cell=7px / 角度25° / 半径係数.60 / ガンマ.72
  色: 暗部 #302016 / 明部 #f3dcbe
```

書き出しは WebP quality 78〜82。ページ側で粒子（SVGノイズ）を
`mix-blend-mode:multiply` opacity .22 で重ねます（`.ph::after` が自動でやります）。

### 差し替え手順

1. 上表の比率で書き出し、`apps/web/public/img/` に配置
2. `apps/web/src/app/page.tsx` の該当 `<img src>` と `alt` を書き換える
   - コラージュ: `/img/scene-trace.svg`
   - 網点バンド: `/img/scene-halftone.png`
   - エディトリアル: `/img/scene-work.svg`
3. 自前写真なら、ページ下部の
   `<p className="phcap">図版はすべて自作のイラストです（写真ではありません）</p>`
   を実態に合わせて書き換えるか削除
