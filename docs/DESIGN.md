## 5\. ビジュアル言語（base44の作り方を踏襲）

base44の「クリエイティブさ」の正体は、写真やイラストの巧さではなく **①彩度の高いフラットな色面 ②その上に粒子質感 ③太い黒文字の製品モックアップ ④コラージュ的な並置** の4点。全てSVGで自作しているので外部素材は不要。

1. **色面 \+ グレイン**  
     
   \<filter id="gr"\>\<feTurbulence type="fractalNoise" baseFrequency=".9" numOctaves="3" stitchTiles="stitch"/\>  
     
     \<feColorMatrix type="saturate" values="0"/\>\</filter\>  
     
   \<rect ... filter="url(\#gr)" opacity=".14" style="mix-blend-mode:multiply"/\>  
     
   → `#ff773c`(朱) と `#3b51e5`(青) の2色を色面に使う。青はコラージュ専用。  
     
2. **製品モックアップは太く**。数値は36〜86pxのGeist 600、`letter-spacing:-1〜-3`、文字は必ず黒 `#181818`（白抜きにしない）。オレンジ色面＋黒文字がbase44の顔。  
     
3. **コラージュ**は3枚並置 — 〈色面＋大グリフ〉〈情景イラスト〉〈細いオレンジ帯〉。比率は `.82fr 1.5fr 84px`。  
     
4. **情景イラスト**はフラットベクター。古民家の内部（梁・障子・畳）＋スマホでスキャンする人物＋点群のドット。彩度を抑えた木色 `#5c4633 / #6b5340 / #c9a06a`、障子 `#fdf9ee`、人物 `#2f3a56`、点群と走査線のみ `#ff773c`。  
     
5. **図面ビジュアルは常に確度3色**。BEFORE（全部グレー）→ AFTER（緑）の対比は製品価値の説明そのものなので、必ず対で見せる。

### 5-6. 写真の使い方

base44のコラージュは〈色面〉〈写真〉〈帯〉の3枚並置。写真は**そのままでは使わず、必ず処理する**。

- グレーディング: R×1.05 / B×0.95（暖色寄せ）、彩度0.95、コントラスト1.10、明度1.04  
- デュオトーン（エディトリアル用）: グレースケール → autocontrast(cutoff 2\) → コントラスト1.35 → colorize(black `#121116`, mid `#7a3428`, white `#ff8c54`)  
- 粒子: SVGノイズを `mix-blend-mode:multiply` opacity .22 で全写真に重ねる（`.ph::after`）  
- ヴェール: 横長写真は左からの `linear-gradient(100deg, .92 → .05)`。文字は左60%以内に収める  
- 被写体は「空き家」ではなく **場をつくっている人**。埃っぽい廃墟の写真は使わない  
- 撮影・差し替えの手順は `CREDITS.md` を参照

### 5-7. テクスチャ面（base44の質感の核）

base44の「クリエイティブさ」で最も効いているのが**テクスチャ**。3種類を使い分ける。

**① 布地（キャンバス織り）の色面** — `.fabric` 大きな見出しを直接乗せる青 `#3b51e5` / 朱 `#ff773c` のパネル。104pxタイルのグレースケール織り目PNGを `background-blend-mode:soft-light,overlay` で2枚重ね。生成コード（Python/PIL）:

noise \= ガウスぼかし(正規分布ノイズ σ=34)

warp \= 26\*sign(sin(x\*π/1.5))\*|sin(x\*π/1.5)|\*\*.5   \# 縦糸

weft \= 同様に y 方向                                \# 横糸

inter \= 16\*sin(x\*π/1.5)\*sin(y\*π/1.5)              \# 交差点

tile \= clip(noise \+ warp\*.55 \+ weft\*.55 \+ inter)   \# 120x120 をタイル

**② 網点（ハーフトーン）写真** — `.htband` 写真を印刷の網点に変換し、その上に薄い色のカードを重ねる。cell=7px / 角度25° / 半径係数.60 / ガンマ.72、色は暗部 `#302016` 明部 `#f3dcbe`。潰れやすいので **autocontrast(cutoff=2) \+ 明度1.12** で必ず持ち上げる。

**③ ドット地** — `.dotted` `radial-gradient(circle at 1px 1px, rgba(28,27,32,.14) 1px, transparent 0)` を 14px間隔。証言・引用など「間をとる」セクションの地に使う。

原則: テクスチャ面は**1ページに3面まで**。連続させず、白い面を必ず間に挟む。
